# CloudBase 安全说明

## 已落实

- 数据库只保存激活码 SHA-256，明文仅在生成响应中出现一次。
- 激活码使用事务完成首次设备绑定，避免并发重复占用。
- 访问凭证使用 HMAC-SHA256 签名并设置 30 天有效期。
- 管理 API 使用独立密钥和恒定时间比较。
- 激活接口按来源限流，所有 API 响应禁止缓存，请求体限制为 16 KB。
- 数据库和前端分离；浏览器中不包含 CloudBase API Key。

## 上线前必须完成

- 两个集合的 Web 客户端权限设为不可读写。
- `ACTIVATION_SECRET`、`ADMIN_SECRET`、`RATE_LIMIT_SALT` 使用不同随机值。
- 卖家后台地址不要公开传播；后台密钥只保存在卖家设备。
- 自定义域名强制 HTTPS。
- 将云函数日志中的管理接口失败、激活失败率和 5xx 纳入告警。

## 依赖审计例外

截至当前锁定版本，腾讯官方最新 `@cloudbase/node-sdk@3.18.3` 仍固定依赖旧版 `axios`、`lodash.set` 和 `lodash.unset`，npm 会报告其传递依赖安全告警。应用没有把用户输入用作 SDK 请求地址、代理配置或动态字段路径，已降低这些公告在本项目中的可利用面，但这不是“零风险”。不要用未经验证的 `overrides` 强行替换 SDK 内部依赖；应在腾讯官方 SDK 发布修复版本后升级并重新执行 `npm audit` 与完整冒烟测试。
